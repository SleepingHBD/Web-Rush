# Web Rush

A responsive, comic-inspired endless rooftop runner built with plain HTML, CSS, and JavaScript.

## Play locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Controls

- `←` / `A` and `→` / `D` — move between lanes
- `↑` / `W` / `Space` — jump
- `F` / `X` — fire a web shot during boss fights
- `P` / `Esc` — pause
- On touch devices: swipe left/right to move, up to jump, or down to fire webs during boss fights

At threat level 5, dodge Green Goblin's pumpkin bombs and use web shots to defeat him.

Threat levels continue rising after that encounter. At threat level 12, Doctor Octopus attacks with mechanical tentacles.

## GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

No build step is required.
